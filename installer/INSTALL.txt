CAD MCP 0.10.0-preview — AutoCAD, Map 3D, Civil 3D 2025–2027 x64

1. Закройте AutoCAD, Map 3D, Civil 3D и Core Console, затем запустите Setup.exe. Установщик сам останавливает broker, отдельное окно CAD MCP и встроенный Codex из папки установленного дополнения. Активный запрос в отдельном окне прерывается; нужный текст сохраните заранее. Установка для текущего пользователя, без прав администратора.
2. Откройте AutoCAD, Map 3D или Civil 3D 2025, 2026 или 2027. При штатном запросе доверия подтвердите конкретную DLL.
3. Откройте CAD MCP → Открыть чат или CADMCPCHAT. В 2025/2026 на .NET 8 откроется палитра; в обновлённых 2025/2026 на .NET 10 и в 2027 — отдельное окно с тем же чатом.
4. Выберите Codex или Claude Code. Codex 0.159.0 входит в комплект; кнопка «Войти» запускает официальный вход. Нужна подходящая подписка аккаунта. Claude Code устанавливается и авторизуется отдельно.
5. Проверьте название DWG сверху. «Использовать выделение» добавляет выбранные объекты к запросу.
6. Модель и глубина рассуждений выбираются в панели. Список берётся из аккаунта; история сохраняется после смены модели.
7. Enter отправляет, Shift+Enter вставляет строку. Редактирование выполняется сразу по вашему запросу. C# применяется по умолчанию, AutoLISP остаётся запасным способом. Ошибка до commit откатывает нативный пакет; Undo отменяет пакет при доступной группе. Stop модели не отменяет принятый CAD-запрос.
8. Перетащите файлы в окно чата. Для сохранения нажмите «Диалог в Word» или выберите ответ и нажмите «Ответ в Word».

Журнал ошибок: кнопка «Журнал ошибок». История и операции: %LOCALAPPDATA%\CadMcp.
Установка: %APPDATA%\Autodesk\ApplicationPlugins\CadMcp.AutoCAD2025.bundle (путь сохранён для обновления).
Удаление: Параметры Windows → Приложения → CAD MCP 2025–2027 Preview.

LT и версии до 2025 исключены. После обновления Autodesk 2025/2026 до .NET 10 снова запустите этот установщик: он выберет адаптер по среде продукта. Смешанные .NET 8/.NET 10 внутри одного года Autodesk не рекомендует, установщик остановится. Специальные функции сетей Civil, Map и СПДС требуют дальнейших адаптеров. Обновлённые 2025/2026, 2027 и вертикальные продукты требуют отдельных живых проверок; сборка SDK их не заменяет.
