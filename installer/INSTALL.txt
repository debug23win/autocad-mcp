CAD MCP 0.3.1-preview — AutoCAD, Map 3D, Civil 3D 2025–2027 x64

1. Закройте AutoCAD и отдельное окно CAD MCP. В меню Пуск выберите «CAD MCP → Остановить MCP broker» (в старой версии — «CAD MCP AutoCAD 2025»). Затем запустите Setup.exe. Установка для текущего пользователя, без прав администратора.
2. Откройте AutoCAD, Map 3D или Civil 3D 2025, 2026 или 2027. При штатном запросе доверия подтвердите конкретную DLL.
3. Откройте CAD MCP → Открыть чат или CADMCPCHAT. В 2025/2026 — палитра; в 2027 — отдельное окно с тем же чатом.
4. Выберите Codex или Claude Code. Codex 0.159.0 входит в комплект; кнопка «Войти» запускает официальный вход. Нужна подходящая подписка аккаунта. Claude Code устанавливается и авторизуется отдельно.
5. Проверьте название DWG сверху. «Использовать выделение» добавляет выбранные объекты к запросу. «Показать объект» выделяет объект результата или содержащую его вставку.
6. Модель и глубина рассуждений выбираются в панели. Список берётся из аккаунта; история сохраняется после смены модели.
7. Enter отправляет, Shift+Enter вставляет строку. Редактирование выполняется сразу по вашему запросу. Ошибка до commit откатывает нативный пакет; Undo отменяет пакет при доступной группе. AutoLISP может оставить частичные изменения. Stop модели не отменяет принятый CAD-запрос; Esc прерывает CAD-команду.

Журнал ошибок: кнопка «Журнал ошибок». История и операции: %LOCALAPPDATA%\CadMcp.
Установка: %APPDATA%\Autodesk\ApplicationPlugins\CadMcp.AutoCAD2025.bundle (путь сохранён для обновления).
Удаление: Параметры Windows → Приложения → CAD MCP 2025–2027 Preview.

LT и версии до 2025 исключены. Специальные функции сетей Civil, Map и СПДС требуют дальнейших адаптеров. 2026/2027 и вертикальные продукты требуют отдельных живых проверок; сборка SDK их не заменяет.
