CAD MCP — предварительная версия 0.11.14, Windows x64

Продукты: AutoCAD, Map 3D и Civil 3D 2025–2027. AutoCAD LT и версии до 2025 не поддерживаются. Установщик определяет фактическую среду AutoCAD 2025/2026: исходные редакции используют .NET 8, обновления 2025.1.4+/2026.1.2+ — .NET 10. После обновления Autodesk установите CAD MCP повторно. Для 2027 предусмотрен отдельный адаптер .NET 10. Ранее живые проверки выполнялись в AutoCAD 2025 с .NET 8. Изменения 0.11.8–0.11.14 и исправления аварий 0.11.2 ещё не проверены в AutoCAD; обновлённые и другие продукты также требуют отдельной проверки.

Официальный Codex CLI включён. Вход выполняется вашим аккаунтом; подписка оплачивается отдельно. Claude Code устанавливается отдельно. MCP разрешает изменения по вашему запросу и сохраняет журнал операций. AutoLISP может оставлять частичные изменения; проверяйте результат.

Перед установкой закройте AutoCAD, Map 3D, Civil 3D и Core Console. Broker, отдельное окно CAD MCP и встроенный Codex из папки дополнения установщик остановит сам. Активное задание в отдельном окне будет прервано; нужный текст сохраните заранее. Установщик не закрывает ваши чертежи автоматически.

Полный нативный бенчмарк запускается только в отдельной сессии AutoCAD без открытых DWG. Причина сообщённого fatal crash AutoCAD 2027 пока не подтверждена; проверки managed-кода не заменяют нативного прогона.

Язык интерфейса и ответов помощника по умолчанию соответствует выбранному языку установки. Документация репозитория остаётся на английском.

C# выключен по умолчанию: включите «Разрешить C#» в панели только для нужной работы. Скрипт выполняется один раз в отдельном acad.exe на копии DWG. Проверенный результат заменяет рабочий чертёж, только если он не изменился. Копии до операции сохраняются; при переоткрытии история Undo сбрасывается. Изменение DWG и рабочие папки в OneDrive запрещены; справочные файлы можно читать. Изоляция и замена ещё требуют проверки в установленном AutoCAD.

Computer Use разрешается отдельно кнопкой «Computer Use: доступ…» для подключённого подписанного AutoCAD. Доступ применяется со следующего хода Codex, не передаётся помощникам и отзывается кнопкой «Отозвать Computer Use». Действия через интерфейс не имеют автоматического отката CAD MCP. Инструмент должен быть доступен в Codex; права Windows и ограничения организации сохраняются.
