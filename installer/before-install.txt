CAD MCP — предварительная версия 0.11.6, Windows x64

Продукты: AutoCAD, Map 3D и Civil 3D 2025–2027. AutoCAD LT и версии до 2025 не поддерживаются. Установщик определяет фактическую среду AutoCAD 2025/2026: исходные редакции используют .NET 8, обновления 2025.1.4+/2026.1.2+ — .NET 10. После обновления Autodesk установите CAD MCP повторно. Для 2027 предусмотрен отдельный адаптер .NET 10. Ранее живые проверки выполнялись в AutoCAD 2025 с .NET 8. Изменения 0.11.6 и исправления аварий 0.11.2 ещё не проверены в AutoCAD; обновлённые и другие продукты также требуют отдельной проверки.

Официальный Codex CLI включён. Вход выполняется вашим аккаунтом; подписка оплачивается отдельно. Claude Code устанавливается отдельно. MCP разрешает изменения по вашему запросу и сохраняет журнал операций. AutoLISP может оставлять частичные изменения; проверяйте результат.

Перед установкой закройте AutoCAD, Map 3D, Civil 3D и Core Console. Broker, отдельное окно CAD MCP и встроенный Codex из папки дополнения установщик остановит сам. Активное задание в отдельном окне будет прервано; нужный текст сохраните заранее. Установщик не закрывает ваши чертежи автоматически.
