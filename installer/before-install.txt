CAD MCP — предварительная версия 0.6.1, Windows x64

Продукты: AutoCAD, Map 3D и Civil 3D 2025–2027. AutoCAD LT и версии до 2025 не поддерживаются. Установщик определяет фактическую среду AutoCAD 2025/2026: исходные редакции используют .NET 8, обновления 2025.1.4+/2026.1.2+ — .NET 10. После обновления Autodesk установите CAD MCP повторно. Для 2027 предусмотрен отдельный адаптер .NET 10. Живые проверки выполнены в установленном AutoCAD 2025 с .NET 8; обновлённые и другие продукты требуют отдельной проверки.

Официальный Codex CLI включён. Вход выполняется вашим аккаунтом; подписка оплачивается отдельно. Claude Code устанавливается отдельно. MCP разрешает изменения по вашему запросу и сохраняет журнал операций. AutoLISP может оставлять частичные изменения; проверяйте результат.

Перед установкой закройте AutoCAD и CAD MCP, остановите broker через меню Пуск. Установщик не закрывает ваши чертежи автоматически.
