CAD MCP — Preview 0.11.7, Windows x64

Products: AutoCAD, Map 3D and Civil 3D 2025–2027. AutoCAD LT and releases before 2025 are unsupported. The installer detects the AutoCAD 2025/2026 runtime: original releases use .NET 8; updates 2025.1.4+/2026.1.2+ use .NET 10. Reinstall CAD MCP after updating Autodesk. AutoCAD 2027 has a separate .NET 10 adapter. Earlier live checks used AutoCAD 2025/.NET 8. Changes in 0.11.7 and crash fixes from 0.11.2 have not yet been validated in AutoCAD; updated and other products also need separate validation.

Official Codex CLI is included. Sign in with your account; subscriptions are separate. Install Claude Code separately. MCP permits edits you request and records operation receipts. AutoLISP may leave partial changes; inspect the result.

Close AutoCAD, Map 3D, Civil 3D and Core Console before installation. The installer stops the broker, standalone CAD MCP window and bundled Codex processes from the plugin directory. Active standalone tasks are interrupted; save any needed text first. The installer never closes your drawings automatically.

Run the full native benchmark only in a separate AutoCAD instance with no open DWGs. The reported AutoCAD 2027 fatal crash remains unexplained; managed tests do not replace native validation.

The interface and default assistant language follow your installation-language selection. Repository documentation remains English.
