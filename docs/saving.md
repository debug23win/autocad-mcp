# Сохранение и автосохранение

## `cad_save`

Агент сохраняет чертёж нативным C#, без AutoLISP `QSAVE`/`SAVEAS`, и только по просьбе пользователя. Три режима:

| `mode` | Что происходит |
|---|---|
| `save` (по умолчанию) | Чертёж записывается в свой DWG, как `QSAVE`: остаётся `.bak` AutoCAD, флаг DBMOD сбрасывается. Безымянный чертёж даёт `SAVE_AS_REQUIRED`, открытый только для чтения — `READ_ONLY_DRAWING`, файл с атрибутом «только чтение» — `READ_ONLY_FILE` |
| `save_as` | Новый абсолютный путь `.dwg`; чертёж дальше работает под этим именем, вкладка чата переходит к новому проекту |
| `copy` | Отдельная копия `.dwg`; рабочий чертёж, его имя и флаг изменений не меняются |

Существующие файлы не перезаписываются (`OUTPUT_EXISTS`), кроме собственного файла чертежа в режиме `save`. Для DXF и PDF есть `cad_export`. `expected_revision` необязателен: сохраняется текущее состояние. Ответ содержит путь, размер, SHA-256, код версии DWG из заголовка файла (например `AC1032`) и `document_state` после сохранения. Если файл не начинается с заголовка DWG (в настройках AutoCAD формат сохранения по умолчанию — DXF), ответ предупреждает об этом.

`save` и `save_as` идут через ActiveX-документ AutoCAD (`AcadDocument.Save`/`SaveAs`), то есть ведут себя как команды AutoCAD: формат по умолчанию из настроек «Открытие и сохранение», файл `.bak`, сброс DBMOD, переименование документа. В Core Console ActiveX-документа нет: `save` записывает базу (`Database.SaveAs`), `save_as` недоступен. `copy` пишет копию через `Wblock` и не трогает живую базу. Сохранение — операция с квитанцией `operation_id`, как правка; после неясного ответа читается `cad_operation_status`.

## Автосохранение

Решение принимает пользователь командой `CADMCPAUTOSAVE`; агент его изменить не может: скрипт `cad_lisp`, упоминающий команду, отклоняется, а сама команда не работает во время скрипта агента.

| Режим | Что происходит |
|---|---|
| Копия (по умолчанию) | Резервная копия изменённого чертежа в `%LOCALAPPDATA%/CadMcp/recovery/autosave/<проект>/`. Файл DWG пользователя не трогается. Хранятся 3 последние копии каждого проекта, рядом — запись `.json` с исходным путём и ревизией |
| Сохранять | Активный чертёж с именем, доступный для записи, сохраняется в свой файл, как `QSAVE`. Остальные открытые чертежи получают резервную копию |
| Выключить | Остаётся только собственное автосохранение AutoCAD (`SAVETIME`) |

Интервал — от 1 до 240 минут, по умолчанию 10. Чертёж сохраняется, только если изменился с последнего сохранения или копии, и не чаще интервала, включая неудачные попытки. Работа идёт в простое AutoCAD: очередь CAD MCP пуста, нет команды, диалога и ожидающего AutoLISP; за один простой — не больше одного чертежа. Ошибка автосохранения не прерывает работу и видна в `cad_diagnostics` (`autosave.last`) и в `document_state.automatic_save`. Переменная окружения `CAD_MCP_AUTOSAVE` (`off`, `copy`, `save`, с интервалом `copy:5`) имеет приоритет — для автоматических прогонов.

Резервная копия открывается отдельно; рабочий чертёж ею не перезаписывать.

Код: `src/CadMcp.Core/AutoSave.cs` (настройки, расписание, ротация копий), `src/CadMcp.AutoCAD/WorkSafety.cs` (`DrawingSaving`, `AutoSaver`). Настройки, расписание и ротация покрыты модульными тестами; само сохранение в AutoCAD проверяется пробой `CADMCPPROBE` (`tests/CadMcp.NativeProbe`) и [контрольным списком](live-checklist.md).
