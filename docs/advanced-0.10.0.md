# CAD MCP 0.10.0

Изменения по согласованным пунктам 1–3 и 6.

## Контракт и проверка результата

Для сложного задания агент сначала формулирует проверяемые требования. `expectations_json` теперь поддерживает `task`, `bounds_size`, `bounds_tolerance`, `type_counts`, диапазоны `minimum`/`maximum`, `review_views` и `visual_requirements`. Размеры проверяются по фактическому чтению базы. Нарушенный или недоступный размерный критерий до commit откатывает пакет.

```json
{
  "task":"Балка Б1",
  "units":"Millimeters",
  "entity_count":1,
  "bounds_size":[5000,100,200],
  "bounds_tolerance":0.01,
  "type_counts":{"BlockReference":1},
  "checks":[
    {"target":"beam","property":"assembly.profile_code","expected":"20Б1"},
    {"target":"beam","property":"assembly.solid_mass_kg","minimum":104,"maximum":107}
  ],
  "review_views":["front","isometric"],
  "visual_requirements":["Сверить силуэт и узлы с референсом"]
}
```

Пример предполагает `assembly_create` с `id:"beam"`, `kind:"beam"`, `parameters:{"length":5000,"profile":"20Б1"}`, без аннотаций, материалом и плотностью 7850 кг/м³. Код сечения не задаёт марку стали.

Критерии `cad_edit` относятся к объектам одного пакета; финальный `cad_verify` должен охватывать все окончательные объекты задания. Панель дополнительно перечитывает handles всех подтверждённых C#-изменений своего чата за ответ, порциями до 500, и выводит их общее количество. Размерные критерии в автоматической сводке относятся к последнему пакету; это явно подписано. При усечении истории проверка помечается неполной. Итоговые ракурсы кадрируются по всем доступным объектам при числе до 500; при большем числе сохраняется текущий масштаб.

Визуальные требования остаются `visual_review_required`, даже если все размерные проверки прошли. Растр и сравнение предоставленных контуров не доказывают точное восстановление 3D-модели из фотографий. Агент должен сравнить реальные изображения, перечислить расхождения и не выдумывать неизвестные размеры. Сохранение подтверждается отдельно по состоянию AutoCAD и файлу.

## Нативные конструкции

`cad_steel_catalog` возвращает 6 номинальных двутавров и 6 круглых труб, размеры в миллиметрах, радиусы сопряжений, источники и теоретическую массу. Данные двутавров основаны на каталоге [ЕВРАЗ Стил Инжиниринг](https://ese.pro/assortments/i-beams-produced/). Масса вычисляется по номинальной геометрии при заданной плотности; наличие и допуски нужно сверять со спецификацией производителя.

Балка/колонна по коду каталога строится одним штатным `Solid3d`, с круглыми сопряжениями полок и стенки. Каталог автоматически переводится в единицы DWG. Арматура получает касательные круговые изгибы; `bend_radius` задаёт радиус осевой линии. Слишком короткие смежные участки отклоняются. Длина и масса включают изгибы. Проверка произвольных самопересечений несмежных участков пока отсутствует.

Лопасть винтовой сваи теперь представляет собой штатное объёмное тело из 48 линейчатых сегментов. Внутренняя часть обрезается по стволу, исключая двойной учёт материала. Масса включает ствол и лопасть. Это приближение винтовой поверхности, а не расчёт несущей способности сваи по грунту.

Старые сборки сохраняют прежнюю геометрию и сообщают ограничения массы: сеточная лопасть не учитывается, прямые стержни могут пересекаться на углах. `assembly_update` пересоздаёт сборку по новой геометрии версии 2. Ведомость читает фактические объёмы штатных тел.

## Стабильность и помощники

Undo/Redo таблиц подавляет автоматические записи пересчёта на время команды истории, сохраняя возможность Redo. Печать PDF временно использует `BACKGROUNDPLOT=0`, чтобы квитанция и проверка файла выполнялись после завершения печати; настройка и исходный лист восстанавливаются. Такое поведение Plot API описано в [документации Autodesk](https://help.autodesk.com/cloudhelp/2021/ENU/OARX-DevGuide/files/GUID-4BD159B2-C691-45A0-BF5D-3EB98874FC9A.htm).

У Codex ограничение чтения применяется к идентификатору MCP-вызова, а не только к названию роли. Основной чат регистрируется перед turn/start; вызовы с другим или отсутствующим `threadId` не могут изменить DWG, выделить объекты, запустить Lisp, выпустить файлы или отменить операции. Это закрывает наследование пишущего подключения встроенным `worker`. Метаданные идентификаторов передаются [официальным клиентом Codex](https://github.com/openai/codex/blob/main/codex-rs/core/src/mcp_tool_call.rs). Все обнаруженные пользовательские роли также получают конфигурацию чтения.

У Claude основной агент может вызывать только `cad_researcher`, имеющего отдельный MCP с серверным запретом записи. Число помощников регулируется прежним переключателем. Подробности и ограничения проверки: [agents.md](agents.md), [validation-0.10.0.md](validation-0.10.0.md).
