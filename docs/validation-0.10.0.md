# Проверка 0.10.0-preview — 5 октября 2026

## Полный AutoCAD 2025

Подключение выполнено к экземпляру AutoCAD, запущенному пользователем вручную. Проверки создавали только собственные тестовые DWG. Финальный прогон `CadMcp.GuiProbe` прошёл 110 проверок:

- Два DWG и разные WPF-панели чата; 20 переключений сохраняют привязки.
- 30 циклов одновременных запросов: линии в проекте A, окружности в проекте B. Native API исполняет их последовательно и восстанавливает исходный активный DWG.
- Undo/Redo одной группы, отмена задания A без отмены B.
- Штатные таблицы, межтабличная формула 40 → 70, Undo → 40, пауза, Redo → 70.
- Лист A3, настройки печати, заблокированный видовой экран, настоящий растр вида.
- PDF одного листа, строгий разбор PDF, QSAVE обоих DWG, GC, повторное открытие с сохранёнными объектами и новым live-id.
- Исходный рабочий чертёж сохранил DBMOD=0.

Ранний прогон обнаружил гонку фоновой PDF-печати: файл появлялся после проверки. Исправление синхронной печати прошло финальный прогон. Это проверка перечисленных сценариев в AutoCAD 2025, без обещания отсутствия всех возможных фатальных ошибок.

## Геометрия и протокол

- Core Console: 20 проверок точности — 12 сечений и теоретических масс, изгиб арматуры, объём и отсутствие пересечения лопасти со стволом, откат неверного габарита, честное состояние непроверенных визуальных требований, сохранение/GC/перерисовка.
- Core Console: 24 проверки таблиц, сборок, ведомостей и тел; 45 общих проверок native MCP/CAD.
- Автоматические тесты: 57 сценариев протокола, контракта, Word, управления задачами и ограничений доступа. Родительский `threadId` допускается к записи; дочерний, отсутствующий идентификатор и отсутствующая регистрация отвергаются до CAD broker.
- Реальный Codex CLI 0.159.0: помощник `worker` получил `access.read_only=true`, основной агент — `false`; одно синтетическое изменение основного агента дошло до записывающего стенда. Стенд не подключался к DWG.
- Официальный Codex CLI прочитал конфигурацию и каталог моделей без запуска задачи модели.
- Claude Code 2.1.273 принял параметры запуска, но живой тест остановился до обращения к модели с HTTP 403: организация отключила подписной доступ Claude Code. Разрешения и протокол Claude проверены локальным стендом, исполнение настоящего помощника Claude не подтверждено.

Сборки: .NET 8 с установленными API AutoCAD 2025 и .NET 10 с официальными SDK 25.0.2, 25.1.1 и 26.0.0. Реальная GUI-проверка выполнена только в AutoCAD 2025; Civil 3D, Map 3D, AutoCAD 2026/2027 и переходные хосты .NET 10 в этом прогоне не запускались.

## Повторение

`tests/CadMcp.GuiProbe` компилирует production-код в отдельную тестовую сборку, чтобы не конфликтовать с установленными DLL. Загрузить её NETLOAD в уже работающий AutoCAD и вызвать `CADMCPGUISTABILITY`; отчёт находится в `probe-output/<id>/result.json` рядом с тестовой DLL. Команда создаёт собственные DWG, не закрывает рабочие документы. При повторных сборках в одном AutoCAD использовать отдельное имя/каталог DLL либо перезапустить вручную.

`CadMcp.Tests.exe --live-subagent-test codex <cli>` и аналог для `claude` — добровольные подписные проверки, исключённые из обычных тестов; они расходуют лимит подписки. Обычный запуск тестов не обращается к настоящим моделям.
