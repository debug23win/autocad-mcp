# Проверка 0.6.0-preview — 1 октября 2026

- 37 общих проверок прошли, включая MCP, провайдеров Codex и Claude, параллельные подключения к broker, помощников, валидацию 3D-планов, журнал правок и экспорт чата.
- На отдельном тестовом DWG в AutoCAD 2025 Core Console прошли 39 проверок: 3D-полилиния, сплайн, сетка, выдавливание, sweep, revolve, поворот вокруг пространственной оси, сфера, конус, клин, тор, объединение, вычитание и пересечение тел. Результаты прочитаны обратно из базы; для булевых операций проверены объёмы и удаление/сохранение инструмента.
- Проверки листов, PDF/DXF, растра, Undo и AutoLISP из версии 0.5.0 также прошли в том же Core Console тесте.
- Локальный broker принимает проверку соединения во время долгой CAD-операции; поиск нескольких CAD-сессий выполняется одновременно. Изменения одного DWG остаются последовательными.
- Компиляция адаптера AutoCAD 2027 и содержимого установщика проверяются отдельно при выпуске.
- Геометрическое соответствие произвольной модели фотографиям не проверяется автоматически. Операции Civil 3D/Map 3D и СПДС нуждаются в тесте в работающих вертикальных продуктах на соответствующих DWG.
