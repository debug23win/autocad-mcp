# Помощники и параллельная работа

Параметр «Помощники» в панели работает с Codex и Claude Code. По умолчанию разрешены до трёх помощников, можно выбрать два, четыре или выключить их. Выбор модели и глубины рассуждений сохраняется отдельно для каждого провайдера; кнопки «Войти» и «Диагностика» обращаются к выбранному официальному CLI. Пользователь может прямо поручить основному агенту разделить задачу: например, одному помощнику прочитать профиль, второму проверить геологию, третьему независимо оценить сечения. Основной агент собирает выводы, выполняет изменения DWG и показывает итоговый вид.

Для Codex панель передаёт официальные параметры `agents.enabled` и `agents.max_concurrent_threads_per_session` в локальный app-server. Для Claude Code панель передаёт временное определение `cad_researcher` через `--agents` и ограничивает число одновременно работающих помощников переменной `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`. Этот помощник получает только CAD-инструменты чтения, без редактирования, AutoLISP и экспорта. Обе схемы используют вход по подписке соответствующего CLI; при большем числе помощников растёт расход лимита модели.

Broker обслуживает одновременные подключения, поэтому долгая CAD-команда не блокирует проверку соединения. Поиск доступных CAD-сессий также идёт параллельно. Внутри одного AutoCAD все обращения к его базе последовательно исполняются в главном потоке: это ограничение CAD API и защита от конфликтующих правок. Помощники ускоряют независимый анализ и контроль, но четыре одновременных запроса к одному DWG не станут четырьмя параллельными транзакциями.

В чате видны краткий текущий статус, ответ основного агента и итоговый снимок текущего вида, когда AutoCAD отвечает. Строки с именами MCP-инструментов не попадают в диалог, историю и Word. Отсутствие снимка помечается как непроверенный результат; сам снимок не доказывает, что DWG сохранён на диск или что модель геометрически точна.

В 0.9.0 Codex также получает роль `cad_reviewer` с отдельной конфигурацией: MCP host запрещает ей изменения, AutoLISP, экспорт, выделение и отмену операций. Основной агент обязан привлекать независимую проверку для сложных результатов при включённых помощниках, исправлять подтверждённые дефекты и повторно проверять геометрию. Свободные роли Codex не объявляются принудительно ограниченными — для проверки предусмотрен именно `cad_reviewer`. Ограничение Claude задаётся списком разрешённых инструментов `cad_researcher`.

У каждого открытого DWG своя вкладка, папка истории, экземпляр провайдера и владелец заданий. Вкладки допускают одновременную работу моделей. MCP наследует идентификаторы сессии и документа; запрос к чужому DWG блокируется, включая рендер. «Стоп» отменяет только операции владельца этой вкладки. Субагенты наследуют её документ. Открытые и закрытые файлы обновляются каждые пять секунд. Путь DWG показан в подсказке вкладки; для нового чата рабочая папка берётся из этого пути. Save As сохраняет текущий диалог до закрытия вкладки; при новом открытии история выбирается по новому пути. Одинаковые имена файлов из разных папок имеют разные папки истории.
