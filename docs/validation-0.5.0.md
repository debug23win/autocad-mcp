# Проверка 0.5.0-preview — 30 сентября 2026

- Общий набор: 33 проверки, включая MCP initialize/tools/list/tools/call, работу с моделями по подписке и аффинную привязку пикселей. Все прошли.
- На установленном AutoCAD 2025 Core Console: 28 проверок. Созданы листы, видовой экран точного масштаба, настроен формат, вставлен блок оформления, выпущены два отдельных PDF и ведомости JSON/CSV. PNG вставлен по опорным точкам в прямой и скошенной ориентации; координаты и невязка прочитаны обратно из DWG. Все проверки прошли.
- PDF AutoCAD 2025 имел некорректный XMP-поток и повторный ключ каталога. Исправление добавляет нормативные объекты служебных данных и новую таблицу ссылок, не меняя объектов страниц. После него `pypdf` в строгом режиме читает страницу без ошибок, Poppler рендерит лист. Повторное исправление не меняет файл.
- Адаптер AutoCAD 2027 собран на официальном `AutoCAD.NET` 26.0.0 с .NET SDK 10.0.401. Установщик включает оба адаптера; SDK-сборки Autodesk не поставляются.
- Чтение и изменение специальных объектов Civil 3D/Map 3D не проверены в работающих продуктах; Civil 3D на этой машине отсутствует. Живой снимок палитры `cad_render` и калибровка по его точкам также требуют интерактивного AutoCAD и остаются непроверенными. Контроль полного проекта, штампов СПДС/ГОСТ и окончательного PDF-комплекта ещё нужен.
