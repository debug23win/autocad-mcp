# Проверка релиза 0.9.0-preview

Дата: 5 октября 2026.

Проверены 50 управляемых сценариев: протоколы Codex/Claude, дополнение работающего задания, журнал и восстановление ответа, запрет чужого DWG для чтения/правок/рендера через настоящий stdio MCP SDK, запрет правок роли проверки, изолированная отмена владельца, формулы и структура DOCX. Реальные запросы к моделям в этом наборе не выполнялись.

Отдельный официальный Codex CLI 0.159.0 принял конфигурацию MCP с привязкой документа и роль `cad_reviewer`; запрос каталога вернул восемь доступных моделей. Проверка не запускала модельный ход и не подтверждает качество решения моделью. Для Claude проверены потоковый протокол и ограниченное определение помощника; живой ход Claude с новым набором функций не запускался.

Core Console AutoCAD 2025 на .NET 8 выполнил 100 проверок в изолированных тестовых DWG: 24 новых проверки таблиц и конструкций, 15 проверок СПДС/таблиц, 45 общей геометрии/листов/выпуска/привязки изображений, один полный AutoLISP callback, шесть размеров и девять устойчивости штампов. Локальные и межтабличные формулы пересчитываются, ручная вставка строки сохраняет ссылку, вставка столбца сохраняет адреса, циклы и удаление источников отклоняются. Граф зависимостей сохраняется в DWG. Все семь типов сборок создаются с положительной массой нативных тел, ведомость меняет массу после удлинения балки. Loft/section/fillet/shell сохраняются, читается BRep, проверка выявляет реальное пересечение тел и наложение текстов. Отдельная нативная проверка chamfer в этом релизе не выполнена.

Резервная копия открывается как DWG, содержит таблицы и сохраняет имя/DBMOD рабочего документа. Синхронные события создания этой копии исключены из счётчика пользовательских правок: полный Lisp callback после копии успешно завершается. Обнаруженная при регрессии недостающая PdfPig зависимость включена во все CAD-адаптеры. Два PDF листов проходят строгий разбор, выходят JSON/CSV ведомости файлов. Размеры и штампы проверены с настоящими Undo/Redo, QSAVE и повторным открытием.

Реальный WebView2/WPF прошёл проверки чтения текста, темы, потокового обновления и позиции прокрутки. Отдельно проверены выбор модели, настройки провайдеров и вложения. Многодокументное переключение через MDI в полном интерфейсе AutoCAD пока не проверено; ограничения идентификаторов и владельцев проверены на уровне MCP и протокола. Нативные операции выполняются последовательно, модели в разных вкладках допускают параллельную работу.

DOCX с инженерными дробями, корнями, индексами и матрицей прошёл OpenXML Validator без ошибок. Файл отрисован установленным Microsoft Word в PDF и страницы проверены визуально. Штатный render_docx.py оказался недоступен из-за отсутствия LibreOffice на Windows; проверка Word использована явно, переносимость отрисовки LibreOffice не заявляется.

Собраны .NET 8 адаптер 2025 и официальные SDK .NET 10 адаптеры 2025/2026/2027. Host и Client публикуются со своим runtime 8.0.31. Civil 3D не установлен; новые операции Civil/Map и запуск продуктов на .NET 10 в живом продукте не проверены. Ранее наблюдавшиеся пользовательские аварии не объявляются все устранёнными: новые тесты их не воспроизвели, но обновление не ремонтирует повреждённые DWG.

Установщик сохраняет проверенную в 0.8.2 остановку только собственных MCP процессов; рабочий AutoCAD не закрывается автоматически. Личные DWG, логи, профили, тестовые PDF и DOCX не публикуются в исходниках и не входят в установщик.
