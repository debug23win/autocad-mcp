# Листы и выпуск

`cad_edit` через штатный C# API создаёт лист (`layout_create`), копирует лист с содержимым (`layout_copy`), задаёт печатное устройство, формат, стиль и ориентацию (`layout_configure`). `viewport` создаёт видовой экран на выбранном листе: размеры `center`, `width`, `height` заданы в пространстве листа; `model_center` и `model_height` задают WCS-фрагмент модели. Масштаб видового экрана — `height / model_height`. По умолчанию он заблокирован. Существующий блок со штампом вставляется обычной операцией `block` с полем `layout`; атрибуты задаются по тегам. `cad_catalog` перечисляет настройки печати, видовые экраны и вставленные блоки листов.

`cad_publish` принимает существующую пустую для результатов папку `output_folder` и `layouts_json` — JSON-массив имён листов в порядке выпуска. Каждый лист выводится в отдельный PDF с порядковым номером. Файлы не перезаписываются. Рядом создаются `cad-mcp-manifest.json` и `cad-mcp-manifest.csv` с именами, размерами и SHA-256. Перед печатью проверяются имена листов и конфликты имён файлов. Если один из листов не напечатался, ведомость содержит уже выпущенные файлы и пометку `partial`.

PDF драйвера AutoCAD 2025 может содержать ошибки служебных объектов. Плагин добавляет исправленную таблицу ссылок и метаданные, сохраняя графику страниц; проверочный файл открылся строгим PDF-парсером и отрисовался Poppler. Контрольная сумма подтверждает состав файлов, но не правильность их изображения. Перед выдачей комплекта нужно открыть PDF, сверить формат, масштаб, штамп, видимые слои и полноту объектов СПДС/ГОСТ. Живой комплект проекта пока не был проверен.
