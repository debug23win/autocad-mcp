# Layouts and publishing

Through native C# APIs, `cad_edit` creates layouts (`layout_create`), copies them with contents (`layout_copy`), and sets plot device, media, style, and orientation (`layout_configure`). `viewport` creates a viewport on a chosen layout: `center`, `width`, and `height` are paper-space values; `model_center` and `model_height` define the model's WCS region. Viewport scale is `height / model_height`; it is locked by default. Insert an existing title-block definition using `block` with `layout`, assigning attributes by tag. `cad_catalog` lists plot settings, viewports, and block inserts on layouts.

`cad_publish` accepts an existing output directory with no conflicting results as `output_folder` and a JSON array of layout names in publishing order as `layouts_json`. Each layout becomes a numbered PDF; files are never overwritten. Adjacent `cad-mcp-manifest.json` and `cad-mcp-manifest.csv` record names, sizes, and SHA-256. Layout names and filename conflicts are checked before plotting. If a layout fails, the manifest lists already produced files and marks the result `partial`.

AutoCAD 2025's PDF driver may produce invalid internal objects. The plugin appends a corrected cross-reference table and metadata while retaining page graphics; a sample passed a strict PDF parser and rendered with Poppler. Checksums verify file identity, not visual correctness. Before delivery, open the PDFs and check paper size, scale, title block, visible layers, and complete SPDS/GOST objects. A live project publication set has not yet been validated.
