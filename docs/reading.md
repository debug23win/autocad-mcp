# Чтение DWG и кэш

`cad_context` возвращает session_id, document_id, revision, имя, единицы, пространство, handles выделения, UCS, вид и версии AutoCAD/.NET. Актуальные операции получают expected_revision.

`cad_search` принимает options_json, например:

```json
{"scope":"model","text":"Колодец","expand_blocks":true,"max_depth":6,"limit":100,"offset":0,"details":false}
```

Области: current/model/layouts/all/selection/view. Фильтры: layer, type (имя .NET или DXF), text, bounds с min/max в WCS. limit 1..500; max_depth 0..12. Следующая страница задаётся result.pagination.next_offset. Количество объектов ограниченной страницы не является общим количеством. Границы используют пересечение bounding boxes; вид — консервативную WCS-оболочку. Перспективный вид требует выделения или явных границ.

Ответ: result.entities и cached. Сводка даёт handles, path экземпляра, root_handle, тип, слой, текст, границы, глубину. details=true добавляет геометрию. path различает одну сущность определения в нескольких вставках; для показа использовать root_handle. Вложенные определения и xref не редактируются как сущности текущего пространства. При неподдерживаемом преобразовании класса возвращается local и ограничение; world_transform сохраняется. Незагруженные xref и специальные свойства не считаются полностью прочитанными.

`cad_snapshot` / `cad_query` остаются ограниченным снимком текущего пространства. `cad_entity_get` читает верхний объект текущего пространства. Размеры возвращают measurement, text_override, dimension_style, text_position и доступные точки geometry; это не полный вычисленный текст со всеми правилами стиля.

Каталоги, снимки и до восьми страниц поиска используют документ, ревизию и пространство. Изменения базы, Undo/Redo и операции плагина повышают ревизию. Search view/selection не кэшируется. Сводка не клонирует полную геометрию; фильтры типа/слоя применяются до подробного чтения.

Результат больше 512 KiB сохраняется в results/<worker-session>. `cad_result_get` принимает archive_id, offset и limit (1..32000 символов), возвращает кусок JSON-текста и next_offset. Для разбора JSON соединить страницы. Данные исторические, с captured_revision; перед изменением перечитать контекст. Архив ограничен 64 файлами / 64 MiB, результат — 16 MiB; старые результаты могут истечь.
