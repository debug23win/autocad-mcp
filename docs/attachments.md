# Вложения в чате CAD MCP 0.3.1

Перетащите файлы из Проводника в любое место окна чата или нажмите «Прикрепить файл». Имена появятся над полем ввода. Кнопка × убирает файл до отправки. Можно отправить сообщение без текста, только с файлами. Файлы остаются на диске в исходных папках; чат их не удаляет и не копирует. Неотправленные вложения не восстанавливаются при следующем запуске.

- До 10 файлов в одном сообщении. Допускаются файлы; папки не разворачиваются.
- PNG, JPEG, WebP и GIF передаются как изображения: локальное изображение для Codex, блок изображения для Claude Code. Не более 7 МиБ на изображение и 21 МиБ суммарно. Общий предел учитывает увеличение размера при кодировании для Claude Code.
- Текстовые файлы до 512 КиБ включаются в сообщение содержимым; общий предел текста вложений — 1 МиБ. Поддерживаются UTF-8, UTF-16 с BOM и Windows-1251 для русских чертёжных записок.
- Остальные файлы, включая DWG и PDF, передаются агенту как абсолютный локальный путь. Это ссылка на файл, а не обещание, что модель уже прочитала его содержание. Агенту нужен подходящий локальный инструмент чтения; если его нет, он должен об этом сообщить. Для DWG активный чертёж в AutoCAD читается инструментами CAD MCP отдельно.

Проверка наличия файла выполняется при добавлении и перед отправкой. История показывает имена отправленных файлов, но не сохраняет содержимое или неотправленные пути. Вложения передаются выбранному пользователем провайдеру в текущем сообщении.
