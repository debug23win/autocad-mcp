# Civil 3D и Map 3D

`cad_vertical_catalog` обращается к API запущенного вертикального продукта и сообщает, доступен ли он. Для Civil 3D каталог ограниченно читает поверхности, трассы, профили и трубопроводные сети; `cad_vertical_get` читает свойства объекта по handle, вложенные профили/части сети, а для поверхности может получить отметки в 1–100 точках WCS. Изменения Civil TIN через `cad_edit`: `civil_tin_create` создаёт поверхность по 3–5000 вершинам `[x,y,z]`, `civil_tin_add_points` добавляет вершины к существующей поверхности. Оба действия требуют загруженного API Civil 3D и выполняются в нативной транзакции. Стиль новой поверхности берётся из шаблона Civil.

Для Map 3D каталог читает код горизонтальной/вертикальной системы координат и имена таблиц объектных данных; `cad_vertical_get` пытается прочитать записи объектных данных выбранного объекта вместе с полями. Данные ограничены 100 записями и 100 полями на запись. DLL Autodesk не поставляются вместе с плагином; API загружается из установленного продукта.

На компьютере разработки доступен обычный AutoCAD 2025 и компоненты Map 3D, но нет работающего Civil 3D. Поэтому специальные операции Civil и чтение объектных данных Map **собраны, но не подтверждены на реальных объектах этих продуктов**. В этой версии нет создания/редактирования трасс, профилей, трубопроводных сетей и данных Map; агент должен сообщать об этих ограничениях и не представлять обычную DWG-геометрию как полноценный объект Civil/Map.
