# Проверка 0.8.0-preview

Дата: 2 октября 2026. Поддерживаемые продукты: AutoCAD, Map 3D, Civil 3D 2025–2027; LT и версии до 2025 не включены.

Проверено:

- 47 автоматических проверок: протоколы, журнал, история, вложения, MCP; дополнение текущего хода Codex и потоковый ввод Claude через записывающие тестовые процессы; отклонённое дополнение не уничтожает текущий ответ. Реальные модели в этих проверках не запускаются.
- Повторно пройдены 45 проверок прежних нативных команд AutoCAD 2025: геометрия, 3D, блоки, листы, PDF/DXF, привязка растра, откаты и журнал операций. Отдельно проверен резервный AutoLISP с управляемыми обратными вызовами. Сборки .NET 10 для 2025/2026/2027 выполнены без ошибок и предупреждений; запуск этих адаптеров на всех продуктовых сочетаниях не проверен.
- AutoCAD 2025 Core Console: локальная формула получает 10; поле со ссылкой на другую таблицу — 20; после правки исходных данных они получают 15 и 30. Формула сохраняется после вставки строки. Проверены объединения, чтение адресов/формул, откат ошибочного пакета, размеры, штрихпунктирная ось, атрибуты и правка бумажного листа без переключения пространства.
- Спецификация формы 7: фактическая ширина 185 мм, заголовок 15 мм, строка примера 8 мм. Основная надпись содержит редактируемые атрибуты. Тестовый DWG сохранён, лист выпущен в PDF; изображение страницы проверено на читаемость и пересечения текста с рамками.
- Настоящие WPF/WebView2: поле дополнения и вложения доступны при работе, выбор модели заблокирован; текст виден в обеих темах, DOM сохраняется, прокрутка не прыгает к началу, формулы выводятся.

Результат не доказывает живую обработку дополнений всеми установленными версиями CLI, нормативное соответствие полного проекта КЖ/КМ или работу вертикальных API на неустановленных Civil/Map. Три дополнительных шаблона КЖ/КМ явно отмечены проектными, а не обязательными формами. Геометрия и правила оформления имеют отдельные пределы проверки; шрифт и проектные данные проверяют отдельно.

Инструменты: 27 MCP, 56 нативных действий C#. Изменения 0.7.0 (критерии качества, восстановление ответа, работа по фото, стабильная прокрутка) также входят в этот выпуск.
