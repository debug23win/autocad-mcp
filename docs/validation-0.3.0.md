# Проверка 0.3.0-preview

Дата: 29 сентября 2026. Windows x64, установленный AutoCAD 2025.1.2 (API 25.0.162.0), .NET SDK 9.0.311 и 10.0.401.

## Подтверждено

- Основное решение, native probe, WPF probe, отдельный клиент и адаптер 2027 собраны без ошибок и предупреждений. Адаптер 2027 использует официальный Autodesk AutoCAD.NET 26.0.0; .NET 10 SDK получен от Microsoft с проверкой SHA-512.
- 27 автономных проверок: framing, Unicode, документы/ревизии, пагинация, кэш, journal/replay, 400+ записей и восстановление незавершённых, повреждённая запись, ошибка записи результата после commit, архив/изоляция/retention, карточки объектов, MCP stdio, провайдеры, выбор модели, отмена, bootstrap broker.
- WPF-проверка настоящих контролов: выбор модели и доступных уровней, сохранение истории и настроек, отключение Codex-контролов для Claude. Снимок интерфейса проверен визуально.
- В настоящем изолированном движке AutoCAD: создание/чтение 11 объектов включая размер, штриховку и solids, Unicode, перемещение/свойства, copy/rotate/scale/mirror/erase, откат первого шага при ошибке второго, конфликт ревизии, вложенный блок глубины 2 с WCS-преобразованием и фильтром границ, поиск после 2500 объектов, стабильные страницы, подробная геометрия размеров и пустое выделение. Целевой поиск 2500+ объектов выполнялся за 79–135 мс на этой машине; это локальный замер, не обещание для любых DWG.
- Производственный AutoLISP wrapper выполнен в Core Console: managed Begin/Finish callbacks и дисковый журнал вернули completed с результатом 3. Wrapper в startup script вызывается явно, поскольку Core Console не обслуживает SendStringToExecute между строками script; это проверка evaluator/callback/journal, не GUI-доставки очереди.
- GUI-прогоны настоящих AutoCAD 2025 и Map 3D 2025: по 20 проверок без ошибок. Подтверждены создание и чтение, replay без дубликатов, правка/удаление, фактический rollback, повторное использование снимка/поиска, сброс кэша после изменения, отмена двух объектов одним Undo, отказ при старой ревизии, автоматическая GUI-доставка AutoLISP с результатом 3, его ошибка и прерывание Esc с записью failed/partial_changes_possible, защита от изменения другого активного DWG. Сравнение Database исправлено для разных managed-оболочек: ревизия использует нативную идентичность базы.
- Manifest выбирает SDK .NET 8 только для R25.0–R25.1, SDK .NET 10 только для R26.0; платформы перечислены AutoCAD|Map|Civil3D, без AutoCAD* и LT. Путь bundle и UpgradeCode сохранены, ProductCode обновлён.

## Требуют завершения

Причина прежних остановок GUI установлена и устранена: /p указывал отсутствующий тестовый профиль, и AutoCAD ожидал подтверждения в модальном окне. Launcher теперь заранее создаёт отдельную копию существующего профиля, использует язык и рабочую папку установленного ярлыка. После завершения собственного процесса восстанавливает прежний выбор профиля и удаляет только свой профиль. Обновление контекста в тесте после Undo запрашивается без старой expected_revision. Рабочие DWG не используются. Скрипт: scripts/test-autocad-gui.ps1; параметр -Product MAP выбирает установленный Map 3D 2025. Результаты: artifacts/gui-probe-ACAD.json и artifacts/gui-probe-MAP.json.

Живые установки AutoCAD/Map 3D 2026/2027 и Civil 3D 2025–2027 отдельно не проверены. Официальная совместимость SDK и успешная компиляция адаптеров не заменяют продуктовые испытания. Специальные свойства СПДС GraphiCS, вертикальные API, загруженные xref и рендер требуют своих проверок. Прогон Map 3D проверяет общие DWG-операции, а не редактирование геоданных.

Рабочие DWG не открывались и не сохранялись. Тесты использовали собственные временные чертежи и изолированные профили; текущий выбор пользовательского профиля восстановлен. Программа установщиком на рабочую установку не обновлялась. Публикация нового релиза GitHub не выполнялась.
