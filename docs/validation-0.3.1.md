# Проверка 0.3.1-preview

Дата: 30 сентября 2026. Дополнение к [проверке 0.3.0](validation-0.3.0.md).

- Собраны основное решение и WPF-панель без ошибок и предупреждений.
- 29 автономных проверок пройдены. Новые проверки охватывают классификацию и ограничения вложений, кириллицу в текстовом файле, отказ от поддельного изображения, отправку текста и изображения в форматах Codex app-server и Claude Code CLI через имитацию процессов.
- Настоящие WPF-элементы показали два вложения и удаление одного. Снимок панели сохранён рядом с установщиком.
- Действующие нативные проверки AutoCAD 2025 и Map 3D 2025 из версии 0.3.0: по 20 проверок. Функция перетаскивания добавлена в панель, но отдельный живой запуск панели внутри AutoCAD с мышиным перетаскиванием ещё не выполнялся.

Прямое чтение бинарного PDF/DWG моделью не заявляется: эти файлы передаются локальным путём. Рабочие DWG и установки Civil 3D/2026/2027 не проверялись на этом этапе.
