# Проверка этапа 3А

Дата: 28 сентября 2026. Итоговая сборка Release: **0 ошибок, 0 предупреждений**. Автономные тесты: **12/12 пройдены**.

## Среда и сборка

- Windows x64; SDK 9.0.311; целевая платформа net8.0 / net8.0-windows.
- AutoCAD API из установленной версии 2025.1.2, managed DLL 25.0.162.0.0.
- ModelContextProtocol 1.4.1; Microsoft.Extensions.Hosting 8.0.1; 37 разрешённых внешних NuGet-пакетов перечислены в `licenses/dependencies.json`.
- Все пять проектов решения собраны: Core, Host, Providers, AutoCAD, Tests. Autodesk DLL не включены в выходную папку расширения.
- NuGet-зависимости получены в каталог проекта; доступ к сети требовал исполнения за пределами ограниченной песочницы. Именованные каналы Windows тестировались в обычном пользовательском контексте.

Последний тест запускает собранный Host.exe и обменивается с ним JSON-RPC через stdio. Он обнаруживает семь инструментов, проверяет маршрутизацию запроса и байты изображения. В процессе разработки этот тест выявил неверное использование поля Data SDK; исправлено через ImageContentBlock.FromBytes.

Тесты провайдеров запускают собственный тестовый EXE, который воспроизводит ограниченный набор сообщений протокола. Они не доказывают авторизацию, доступ по подписке или полную совместимость с реальными CLI. Схема Codex сверена с generate-json-schema установленного CLI 0.154.0; запросы моделям не отправлялись.

## Что не выполнялось

- Загрузка нашей DLL в AutoCAD/Map, открытие или изменение DWG.
- Запуск реального Codex app-server или Claude Code для диалога, вход в аккаунты, чтение токенов.
- Проверка рендера, работы ленты/палитры и СПДС GraphiCS на живом документе.
- Установка расширения в системные каталоги, изменение доверенных путей или конфигураций MCP-клиентов.
- Публикация GitHub-репозитория, PR или релиза.

Границы возможностей и инструкция запуска находятся в README. Подготовленные адаптеры не равнозначны проверенной интеграции. Следующий контрольный шаг — согласованный этап 3Б по `docs/live-checklist.md`.

Примечание среды: первый запуск dotnet с отдельным DOTNET_CLI_HOME сообщил о создании сертификата разработки ASP.NET; команда trust не выполнялась. В скрипте сборки дальнейшая автоматическая генерация отключена. Прототип не использует HTTPS-сервер.
