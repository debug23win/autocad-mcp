## Dependencies

ModelContextProtocol 1.4.1 and dependencies are locked in `packages.lock.json`. `licenses/dependencies.json` records resolved NuGet packages, hashes, and declared licenses. Microsoft packages declare MIT; package license/additional-notice texts are retained.

MCP SDK declares Apache-2.0, but upstream v1.4.1 LICENSE also documents an MIT transition; the entire text is preserved in `licenses/mcp-sdk-LICENSE.txt`. Do not simplify this to all third-party code being Apache-2.0.

AutoCAD managed DLL references use `Private=false` and must not enter build payloads. At this historical audit stage, SPDS, models, and official CLIs were not embedded. Their terms remain with the respective vendors; later bundled components have their own release-specific notices.

The audit covers listed imports/current dependencies, not every reviewed repository. Update it before new imports/public releases.
