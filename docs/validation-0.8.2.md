# Обновление установщика и проверка размеров 0.8.2-preview

Дата: 2 октября 2026.

Установщик и удаление автоматически останавливают процессы `CadMcp.Host.exe`, `CadMcp.Client.exe` и встроенного `codex.exe`, только если их исполняемые файлы находятся внутри папки установленного дополнения. Сначала проверяется отсутствие `acad.exe` и `accoreconsole.exe`. Рабочий AutoCAD не завершается автоматически. Активные задания в отдельном окне CAD MCP прерываются.

Broker получает штатный запрос остановки через его собственный pipe, извлечённый из командной строки конкретного установленного процесса. Оставшиеся процессы завершаются, затем установщик повторно проверяет их отсутствие. Одноимённые процессы из других папок не завершаются. Если остановка не удалась, обновление файлов не начинается; причина и PID показываются в сообщении и журнале установки.

`tests/InstallerProbe/run.ps1` собирает отдельный минимальный Inno Setup с тем же `installer/processes.iss`. Проверены четыре сценария: защита работающего AutoCAD с сохранением всех процессов MCP; автоматическая остановка установленного broker/клиента/Codex; сохранение одноимённого host из другой папки; повторная установка без работающего MCP. Процессы создаются только для этого теста; имитация `acad.exe` является переименованным тестовым apphost, Autodesk AutoCAD для проверки установщика не запускается. Настоящее дополнение пользователя не переустанавливается этим тестом.

Отдельная нативная проверка `tests/CadMcp.CoreProbe/DimensionProbe.cs`: в именованном тестовом DWG созданы 24 параллельных, 24 повёрнутых, 24 радиальных и 24 диаметральных размера, два стиля с засечками/стрелками и восемь листов со штампами. Проверены редактирование текста, три цикла пересоздания размерных блоков/перерисовки/сборки временных оболочек, правильные измерения, чтение каталога, сохранение и повторное открытие. После настоящих UNDO/REDO и QSAVE все 96 размеров читаются, значения сохранены, DBMOD равен нулю. Шесть проверок прошли в AutoCAD Core Console 2025 на .NET 8.

У пользователя зафиксированы разные аварии: ранее воспроизведённое повреждение атрибутов и отложенное чтение каталога исправлены в 0.8.1; отдельно получены исключение `acdim.crx ARX` и запись Windows о падении в `acdb25.dll` с `0xC0000005`. Нельзя подтвердить их одинаковую причину по модулю и адресу. Новый тест размеров не воспроизвёл эту аварию. Исправления 0.8.1 включены в 0.8.2, но устранение всех возможных причин аварий не заявляется. Повреждённый ранее сохранённый DWG требует отдельной проверки копии; обновление дополнения само по себе не восстанавливает его содержимое.

Нативные проверки не запускаются на рабочих чертежах. Журналы, дампы, DWG и временные тестовые файлы не входят в публичный репозиторий или установщик.

Общая регрессия: 47 автоматических проверок протоколов, очередей, истории, дополнения заданий и обоих провайдеров прошли. Адаптеры .NET 8 и .NET 10 для 2025–2027 собраны; Host и Client публикуются с собственным runtime 8.0.31. Проверка сведений об уязвимостях NuGet во время первой сборки была недоступна из-за сетевого ограничения; компиляцию и локальные проверки это не остановило. Живые проверки обновлённых продуктов на .NET 10 и вертикальных API по-прежнему не проведены.
