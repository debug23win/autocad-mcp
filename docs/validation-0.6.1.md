# Проверка 0.6.1-preview

Обновление закрывает несовместимость .NET после перехода AutoCAD 2025.1.4 и 2026.1.2 на .NET 10. Установщик определяет среду каждого установленного выпуска по `acdbmgd.runtimeconfig.json` и выбирает соответствующий адаптер. Если продукты одного выпуска используют разные среды, установка останавливается.

## Проверено

- AutoCAD 2025 на этой машине по `acdbmgd.runtimeconfig.json` использует .NET 8; для него сохраняется исходный адаптер.
- Адаптеры 2025.1.4+ (`AutoCAD.NET` 25.0.2), 2026.1.2+ (`AutoCAD.NET` 25.1.1) и 2027 (`AutoCAD.NET` 26.0.0) собраны с нулём предупреждений и ошибок.
- Решение .NET 8 и сам установщик 0.6.1 собраны. Установщик содержит четыре DLL адаптера для поддерживаемых сред 2025–2027; сборки SDK Autodesk в пакет не включены.
- Проверка общего тестового проекта пройдена частично: первые шесть проверок успешны; тест локального канала связи в этой среде дважды завершился по тайм-ауту до остальных проверок. Он не проверяет новую логику установщика.

## Требует живой проверки

Обновлённые продукты 2025/2026 и AutoCAD 2027 на этой машине не установлены. Загрузка их адаптеров, открытие окна чата и операции с DWG в этих выпусках пока не подтверждены. После обновления Autodesk нужно повторно запустить установщик CAD MCP с закрытым AutoCAD.

Основание: [сообщение Autodesk о переходе на .NET 10](https://www.autodesk.com/support/technical/article/caas/sfdcarticles/sfdcarticles/AutoCAD-and-Toolsets-Requirements-for-products-affected-by-the-Microsoft-NET-10-transition.html), [предупреждение о смешанных обновлениях](https://help.autodesk.com/view/ACD/2026/ENU/?caas=caas/sfdcarticles/sfdcarticles/AutoCAD-2026-1-2-and-Toolset-Products-Crashes-After-Updating-To-NET-10-Based-Builds.html).
