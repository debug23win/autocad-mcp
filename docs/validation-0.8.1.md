# Исправление аварий 0.8.1-preview

Дата: 2 октября 2026.

По журналу Windows подтверждён AccessViolation в чтении `AttributeDefinition.TextString` из `cad_catalog` после создания штампов. Независимый тест восьми листов на исходном коде 0.8.0 воспроизвёл завершение AutoCAD Core Console с кодом `0xC0000005` после принудительной очистки временных оболочек и при чтении каталога.

Исправлено:

- Многострочный атрибут штампа сначала добавляется в транзакцию, затем инициализирует собственный MText; правка выполняется через копию, возвращённую API атрибута. Произвольный новый MText не подставляется вместо внутреннего объекта.
- Каталог возвращает материализованные массивы значений, включая атрибуты и листы. В ответах не остаются отложенные обращения к открытым объектам DWG.
- Ответы чтения превращаются в независимый JSON на CAD-потоке до закрытия транзакции и блокировки документа. Поток передачи данных не читает нативные объекты AutoCAD.

Проверка исправления: восемь штампов, принудительная сборка временных оболочек, чтение атрибутов, сериализация каталога после закрытия транзакции, сохранение/повторное открытие DWG; затем настоящие UNDO/REDO и сохранение через `(command-s "_.QSAVE")` в отдельном именованном тестовом DWG. Исходная версия падает, исправленная завершает эти проверки.

Снимок с `VEVAL-STR+ ARX` относится к выполнению AutoLISP; журнал операции показывает QSAVE после создания листов. Совпадение с повреждением объектов штампа согласуется с воспроизведением, но не доказывает, что все аварии внутри AutoCAD имели одну причину. Непроверенные вертикальные API и совместимость всех сочетаний продуктов/обновлений сохраняют ограничения 0.8.0.

Проверено чтение копии рабочего DWG: контекст, каталог и поиск завершились без ошибки, снимок ограничен заданной выборкой; ревизия и DBMOD до/после равны нулю. Оригинальный файл не изменялся. Повторно пройдены 45 прежних нативных проверок и 15 проверок таблиц/оформления; резервный AutoLISP завершился с корректным результатом. Лист выпущен в PDF и проверен визуально: текст штампа и таблицы читается.

Проверки выполняются на отдельных файлах. Рабочие чертежи, журналы и дампы пользователя не публикуются.

Общая регрессия: 47 автоматических проверок протоколов, истории, очередей и MCP пройдены. Обновлённые адаптеры .NET 10 для 2025/2026/2027 собраны без ошибок и предупреждений; живые проверки этих адаптеров не проводились.

Справка API: [MTextAttributeDefinition](https://help.autodesk.com/cloudhelp/2026/ENU/OARX-ManagedRefGuide/files/OARX-ManagedRefGuide-Autodesk_AutoCAD_DatabaseServices_AttributeDefinition_MTextAttributeDefinition.html), [UpdateMTextAttributeDefinition](https://help.autodesk.com/cloudhelp/2026/ENU/OARX-ManagedRefGuide/files/OARX-ManagedRefGuide-Autodesk_AutoCAD_DatabaseServices_AttributeDefinition_UpdateMTextAttributeDefinition.html).
