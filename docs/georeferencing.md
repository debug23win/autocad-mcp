# Геометрическая привязка изображений

## Растр в DWG

Операция `image_attach` в `cad_edit` принимает абсолютный `path` к PNG, JPEG, TIFF или BMP и `control_points` из 3–20 пар `{ "pixel": [x,y], "world": [x,y,z] }`. Начало пиксельных координат — левый верхний угол изображения, X вправо, Y вниз. Координаты DWG — WCS в текущих единицах чертежа; все опорные точки должны иметь одинаковую Z. Опорные точки не должны лежать на одной линии. Плагин подбирает двумерное аффинное преобразование, возвращает его коэффициенты и среднюю/максимальную невязку, затем вставляет обычный `RasterImage` AutoCAD с этой ориентацией. Данные остаются внешним файловым источником DWG: переносить чертёж нужно вместе с растром.

Пример:

```json
[{"op":"image_attach","name":"План_съемки","path":"C:\\Проект\\plan.png","control_points":[{"pixel":[0,0],"world":[500000,6200000,0]},{"pixel":[2000,0],"world":[500100,6200000,0]},{"pixel":[0,1000],"world":[500000,6199950,0]}]}]
```

Три точки задают преобразование точно; четвёртая и последующие позволяют оценить расхождения. Качество привязки нельзя установить только по трём точкам: для ответственных чертежей нужны независимые контрольные точки. Аффинная модель учитывает перенос, масштаб, поворот и скос. Перспективный снимок или рельефная фотография требуют отдельного ортотрансформирования. Координатная система Map 3D не назначается автоматически по числам WCS: код CRS должен быть известен отдельно.

## Снимок вида AutoCAD для агента

`cad_render` возвращает PNG, его фактический размер в пикселях и `image_id`. Точное соответствие пикселя координатам DWG задаёт `cad_image_register` по 3–20 известным точкам **именно этого снимка**. Результат содержит коэффициенты `pixel_to_world_x/y`, углы изображения в WCS, невязку и ревизию DWG. `cad_image_point` затем переводит список координат из пикселей в WCS или обратно. После изменения вида нужно получить новый снимок и привязать его заново. Устаревшее изображение помечается `historical`.

Одних параметров `ViewTableRecord` недостаточно, чтобы обещать точное соответствие пикселей: `CapturePreviewImage` не документирует обрезку и масштабирование готового PNG. До калибровки агент использует структурную геометрию DWG для точных построений, а снимок — только для визуального понимания.
