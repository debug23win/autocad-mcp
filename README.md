# CAD MCP — AutoCAD, Map 3D и Civil 3D 2025–2027

Версия 0.4.0-preview. Открытый MCP-сервер и чат для работающего AutoCAD. Новый код — Apache-2.0; лицензии заимствований и зависимостей приведены в NOTICE, docs/provenance.md и licenses/.

## Что реализовано

15 MCP-инструментов и 24 вида нативных действий. Слои, линии, окружности, дуги, точки, эллипсы, полилинии, прямоугольники, TEXT/MTEXT, вставки и определения блоков, листы, размеры, штриховки, параллелепипеды и цилиндры; перемещение, копирование, поворот, масштаб, отражение, свойства и удаление. C# API AutoCAD используется по умолчанию также для PDF/DXF-экспорта. Пакет правок выполняется в транзакции с чтением конечного результата; ошибка до commit откатывает пакет. При доступной штатной Undo-группе один Undo отменяет пакет. AutoLISP остаётся запасным путём для операций без нативного адаптера и не гарантирует атомарный откат.

cad_search читает базу DWG за пределами ограниченного снимка. Области: текущее пространство, модель, листы, всё, выделение, текущий вид; фильтры по слою, типу, тексту и WCS-границам. Вложенные блоки и загруженные xref раскрываются с путём экземпляра и преобразованием в мировые координаты. Сводка не выгружает все вершины и свойства; детали запрашиваются отдельно. Динамические блоки возвращают доступные динамические свойства, размеры — точки построения и измерение. Специальные свойства СПДС GraphiCS, Map и Civil явно отмечаются как частичные.

Каталоги, снимки и целевые поиски кэшируются по документу, ревизии и пространству. Выделение и вид перечитываются. Большие результаты сохраняются в ограниченном архиве с постраничным чтением и помечаются как исторические. Журнал изменений сохраняется на диск до запуска операции и после результата. Ограничения в 128 изменений больше нет; в памяти остаётся небольшой кэш завершённых записей. Если запись уже выполненного результата на диск не удалась, ответ сохраняет сведения о выполненном изменении и сообщает предупреждение.

Панель показывает активный DWG и использует выделение. Список найденных объектов из окна чата убран. HTML-диалог отображает Markdown, локальные изображения и формулы KaTeX, автоматически следует светлой/тёмной теме AutoCAD, показывает доступные краткие сведения о ходе рассуждений, действиях инструмента и время ожидания. Можно сохранить весь диалог или выбранный ответ в Word. Формулы в Word пока сохраняются как исходная запись, без преобразования в редактируемые формулы Word. Доступны проверка подключения, вход и диагностика Codex, журнал ошибок, выбор модели и глубины рассуждений. Enter отправляет, Shift+Enter вставляет строку. История и настройки сохраняются. Stop прекращает работу провайдера; уже принятый CAD-запрос может завершиться.

Начиная с 0.3.1 файлы можно перетащить в окно чата или выбрать кнопкой. Перед отправкой они видны в списке и удаляются по одному. Небольшие текстовые файлы передаются с содержимым; PNG/JPEG/WebP/GIF идут изображением через протокол провайдера. Прочие файлы, в том числе DWG и PDF, передаются как локальные пути: агент должен иметь средство их прочитать и явно сообщить, если оно недоступно. См. [вложения](docs/attachments.md).

В 0.3.2 устранён повторяющийся `REVISION_CONFLICT` при чтении чертежей со специальными объектами: побочные события чтения больше не считаются пользовательской правкой. Чтение возвращает фактическую ревизию, а старые страницы снимка помечаются как исторические. Для редактирования точная ревизия по-прежнему обязательна. Процесс Codex дожидается завершения после ответа; временная занятость диалога повторяется ограниченное число раз. Перегрузка выбранной модели показывается понятным сообщением с предложением сменить модель.

В 0.4.0 добавлены создание определений блоков из существующих объектов, листов, точек и эллипсов через C#; PDF/DXF выводит файл и возвращает его размер и SHA-256. На тестовом пустом DWG в AutoCAD 2025 эти операции прошли Core Console; PDF проверен как созданный непустой файл, но визуальную правильность листа нужно проверять отдельно. Для Civil 3D/Map 3D и СПДС чтение специальных объектов дополнено ограниченными именованными свойствами при наличии их managed-сборок; их полная геометрия и редактирование ещё требуют отдельных API-адаптеров. [Схема и сравнение реализаций](docs/capabilities.md).

Codex 0.159.0 включён в установщик. Работа по подписке использует официальный CLI и вход своим аккаунтом. Модели загружаются из его каталога. Смена модели сохраняет диалог. Инструменты своего MCP разрешаются автоматически в процессе приложения, без изменения пользовательского .codex/config.toml. Claude Code устанавливается и авторизуется отдельно.

## Совместимость

| Продукты / годы | Адаптер | Интерфейс | Проверка |
|---|---|---|---|
| Полный AutoCAD и Map 3D 2025 | API 2025, .NET 8 | Палитра из ленты | Общие DWG-операции: по 20 GUI-проверок; нативный движок AutoCAD |
| AutoCAD, Map 3D, Civil 3D 2026; Civil 3D 2025 | Совместимый API 2025, .NET 8 | Палитра из ленты | Сборка и ограничения загрузчика; отдельные продуктовые установки ещё не проверены |
| AutoCAD, Map 3D, Civil 3D 2027 | Официальный AutoCAD.NET 26.0.0, .NET 10 | Отдельное окно из ленты | Сборка официального SDK; живой запуск ещё не проверен |

AutoCAD LT и версии до 2025 исключены по согласованному объёму. Будущие версии после 2027 не включены автоматически. Совместимость базового DWG API не означает готовность специальных операций с сетями Civil, геоданными Map, проверкой ГОСТ/СПДС или выпуском комплектов.

Autodesk подтверждает совместимость SDK 2025 с AutoCAD 2026 и необходимость SDK 2027 / .NET 10 для AutoCAD 2027: [официальная таблица](https://help.autodesk.com/cloudhelp/2027/ENU/AutoCAD-Customization/files/GUID-A6C680F2-DE2E-418A-A182-E4884073338A.htm). Пакет SDK 2027 опубликован Autodesk в [NuGet](https://www.nuget.org/packages/AutoCAD.NET/26.0.0). SDK-сборки Autodesk не распространяются в установщике.

## Установка

1. Закрыть AutoCAD и окно CAD MCP, остановить broker через меню «Пуск → CAD MCP → Остановить MCP broker». Установщик не закрывает пользовательские чертежи.
2. Установить для текущего пользователя. Папка обновления: %APPDATA%/Autodesk/ApplicationPlugins/CadMcp.AutoCAD2025.bundle.
3. Запустить поддерживаемый продукт. При запросе доверия разрешить конкретную сборку. Не нужно менять SECURELOAD глобально.
4. Открыть «CAD MCP → Открыть чат» или CADMCPCHAT. Для Codex нажать «Войти»; Claude авторизовать через его CLI.

Внешний MCP-клиент запускает Contents/Host/CadMcp.Host.exe без аргументов. Broker стартует автоматически. Панель привязана к запустившей её CAD-сессии и передаёт агенту активный DWG; инструменты дополнительно проверяют документ и ревизию.

Данные пользователя: %LOCALAPPDATA%/CadMcp/chat, logs/panel.log, operations/<worker-session>, results/<worker-session>. После перезапуска AutoCAD создаются новые идентификаторы сессии и документа; прежний журнал служит аудитом. Неизвестный результат изменения нельзя автоматически повторять — сначала проверить чертёж.

## Сборка и проверки

Windows x64; .NET SDK для net8 и отдельный SDK для net10; установленный AutoCAD 2025 для ссылок палитры. Lock-файлы и контрольные суммы CLI включены. Autodesk DLL используются только для компиляции.

Из корня: scripts/build.ps1, scripts/test.ps1. Нативные проверки: собрать tests/CadMcp.CoreProbe и запустить scripts/test-autocad-core.ps1; собрать tests/CadMcp.NativeProbe и запустить scripts/test-autocad-gui.ps1 (для установленного Map 3D 2025 — -Product MAP). Core Console работает с /isolate и своим профилем; GUI-проверка создаёт собственные пустые DWG и заранее копирует зарегистрированный профиль, чтобы /p не вызывал модальный диалог. Launcher завершает только свой процесс, восстанавливает прежний выбор профиля, если тот ещё указывает на тестовый, и удаляет свой профиль. Рабочие DWG не открываются.

Для установщика сначала восстановить Host и Client для win-x64, SelfContained=true, RuntimeFrameworkVersion=8.0.31, адаптер 2027 — SDK .NET 10. Затем scripts/prepare-codex.ps1 -Destination <папка-комплекта> и scripts/build-installer.ps1 -IsccPath <Inno-Setup-6.7.3/ISCC.exe> -CodexDir <папка-комплекта> -DotNet2027 <SDK10/dotnet.exe>.
